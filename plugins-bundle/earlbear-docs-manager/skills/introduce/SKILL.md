# earlbear-docs-manager

Author and manage documentation across the EarlBear ecosystem — Google Drive docs, the knowledge base, decision docs, and CLI references for ebdocs, ebshop, and ebjira.

## Skills

| Skill | Purpose | Invoke |
|---|---|---|
| `authoring-drive-docs` | Write markdown that survives `ebdocs sync push` — formatting rules for headings, lists, mermaid, code blocks, and tables | `/earlbear-docs-manager:authoring-drive-docs` |
| `preparing-decision-docs` | Prepare async checkbox decision docs when work is blocked on >3 user decisions with real trade-offs | `/earlbear-docs-manager:preparing-decision-docs` |
| `building-knowledge-base` | Mental model and folder semantics for `earlbear-content/gdocs/knowledge-base/` — placement rules, one-file-per-concept, frontmatter | `/earlbear-docs-manager:building-knowledge-base` |
| `leveraging-gdocs-cli` | Quick reference for all ebdocs CLI commands — create, read, write, share, comment, export, deep linking | `/earlbear-docs-manager:leveraging-gdocs-cli` |
| `leveraging-shopify-cli` | Quick reference for all ebshop CLI commands — products, orders, customers, collections, themes, analytics | `/earlbear-docs-manager:leveraging-shopify-cli` |
| `developing-clis` | Battle-tested methodology for designing, building, testing, and documenting CLIs using parallel Claude Code agents | `/earlbear-docs-manager:developing-clis` |
| `refresh-living-docs` | Detect stale documentation — CLI command trees, Makefile targets, living docs table, skill references | `/earlbear-docs-manager:refresh-living-docs` |
| `refine-working-model` | Primary TPM skill — work taxonomy, delivery SOPs, domain model evolution, capacity planning, Jira setup | `/earlbear-docs-manager:refine-working-model` |
